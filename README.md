# Copperas Cove Money Trail

Independent municipal records research site tracking anything that touches public money: budgets, actual expenditures, payroll and benefits, water, wastewater, solid waste, golf course, Dominion/Fort Cavazos, capital projects, debt, grants, taxes, fees, contracts and vendors.

## Research pattern
Every source record links to both the current/original source and a Wayback Machine history URL. Historical claims should preserve the original URL and, when an exact capture is identified, add the dated snapshot URL rather than replacing the history URL.

## Accessibility
Responsive mobile layout, keyboard-operable search and filters, visible focus states, skip link, semantic landmarks, aria-expanded burger menu, Escape-to-close behavior, reduced-motion support and high-contrast text. Keep additions compatible with WCAG 2.2 AA.

## Deploy
Static site. Upload all files together to GitHub and deploy the repository root to Vercel or Cloudflare Pages. No build command required.

## Archive-first evidence rule
The source vault prioritizes records that the City of Copperas Cove published publicly. Current City URLs are paired with Wayback history for the exact URL. Historic City Archive Center collections and ACFRs back to 2002 are indexed. Public archived copies are used before relying on PIR/open-records requests.


## Harvest status
This build individually indexes the City financial-report archive from January 2007 through May 2022 (164 monthly PDFs), the ACFR/CAFR series from 2007 through 2025, and the currently exposed 2025–2026 unaudited monthly reports. Existing budget, capital, personnel, water, wastewater, solid-waste, golf-course, Dominion, fee and ordinance records remain indexed. Every record automatically receives a Wayback history link for its exact source URL. Gaps reflect documents not listed by the City's current archive index and are not silently invented.
